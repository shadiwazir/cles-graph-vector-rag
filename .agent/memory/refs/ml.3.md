# ml.3 Training data build (ADR 0014)
- Fixes done first (user request): likelihood cap by evidence (inference/calibration.py, warnings in advisor) and advice schema enums for expected_outcome/expected_remedies (+ if/then: dismissed => no remedies); advice prompt v1. 96 tests then.
- Design points decided on my own (documented in ADR 0014): targets are written with hindsight shown to the writer only; first route must equal the real outcome/remedies; citations only from the example's own retrieved passages (stricter than the runtime verifier); likelihood capped by evidence so the model does not learn confident claims without evidence; paid generations cached in training_targets (Flyway V3) keyed by example + input hash + model; eval examples retrieve with as_of = split date (index of training-era docs only, rule L5).
- Pack contract grew: training.yaml (questions per stage) and target_prompt.md are now required files.
- Dry run on the 15 samples: 59 examples (12 train docs, 3 eval docs; split date 2026-10-09; evidence mix below), est input tokens 296k, est cost $0.89 at gpt-5.4-mini prices (unverified), real cost higher (reasoning tokens). Evidence mix: train weak 11, moderate 31, strong 5; eval weak 1, moderate 7, strong 4. Context docs per example 0-6. Sample dates span one week (plus 2018), so contexts are thin: expected.
- Not run yet: real generation (needs user approval, cost). Known limits: writer sees only the extraction summary of what happened; first route always matches reality; dataset not yet in DVC.
