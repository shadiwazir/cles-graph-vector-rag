# ob.3 Tools in every run (ADR 0019), 2026-11-14

- User direction: MLflow, DVC and the observability stack are part of every change (project is a PoC for another project, never released); build them into the workflow end to end, tell openly about concerns. See auto-memory feedback-tools-in-every-change.
- Built in one session: cles/tracking.py (best-effort MLflow per stage via stage_main; eval run per system), cles/lineage.py (git commit and DVC hashes; moved out of manifest to avoid a circular import), mlflow_import.py (SQLite to server, registry via create_model_version because MLflow 3.18 register_model wants a logged model), full `mlflow` as core dependency (mlflow-skinny + mlflow clobbered each other's package directory after `uv sync`), MLflow server 3.18.0 with --serve-artifacts, OTel gauges (stage_value, eval_quality, eval_count, drift_violations), Collector metric_expiration 60m, Grafana dashboard cles-quality (14 panels), Prometheus alerts.yml (10 rules) with promtool tests, drift_check stage + eval/thresholds.yaml + eval/baseline.json, Flyway V4 (request_audit.environment), adapter_version in audit, POST /feedback + page buttons, export_extractions stage (+ manifest extraction_hash), dvc.yaml metrics + metrics/eval.json, pipeline steps (infra full stack, snapshot, drift, judge, alerts-test, mlflow-import), judge (pack judge_prompt v2 + judge_schema, judge_eval, judge_calibrate, labels in explorer with blind mode), strip_context baseline system finetuned_noretrieval (needs a GPU).
- Verified: stage run, eval runs, imported training runs and registry version visible in MLflow; Phoenix has traces; Prometheus has eval and stage gauges; Grafana dashboard reads them; promtool tests pass; DVC tracks exports, eval, runs; drift_check runs (0 violations; online check skipped without live traffic).
- Mistakes: judge prompt first lacked the schema and then the model used its own shape: 144 invalid judgements cost $0.83 for nothing (should have tried 3 examples first); test and smoke requests polluted request_audit, so drift_check showed false violations (fixed with environment column); `uv sync` removed packages and broke the mlflow import (fixed).
- Open and honest: no Alertmanager receiver; alert thresholds and drift thresholds are placeholders; judge uncalibrated until 30+ lawyer labels; the judge model is the same family as the OpenAI baseline (self-preference bias); retrieval benchmark has only 15 questions (recall@1 0.73, recall@3 0.93, MRR 0.82 on 107 decisions); fine-tuned-without-retrieval baseline not run (GPU needed); GPU resource metrics (DCGM) and Postgres/Neo4j exporters not added; DagsHub evaluation and cloud DVC remote not done (PoC stays local); acceptance thresholds for docs/05 still to be set with the user.
