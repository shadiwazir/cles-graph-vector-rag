## Update: first real-model API run (2026-11-15, user approved one question)
- Setup: uvicorn with ALLOW_EXTERNAL_GENERATOR=true, gpt-5.4-mini, synthetic scenario modelled on the public decision R. v. Naqvi (2026 ONCA 719): Crown considering appeal of a 2.5-year sentence for sexual interference and luring a 14-year-old.
- Result: 14.2 s end to end; evidence strength moderate (retrieval) ; 3 routes, 9 citations, 0 failed, 0 overruled; sources from 719 and 727; scope and disclaimer present; no warnings. Cost not measured (single call, estimate about a cent or two); token counts are in the generate span only when telemetry is on.
- Quality notes: advice is grounded and hedged, quotes are real. Weak spots to remember: (1) the verifier proves a quote exists, not that it supports the claim (e.g. 719 para 50 is the respondent's argument; the model attributed it correctly in reasoning, but nothing enforces that) -> faithfulness judge/lawyer review needed; (2) route 1 likelihood "high" while evidence strength is moderate: confidence calibration is not constrained; (3) odd remedy strings like "No remedy if appeal dismissed" in expected_remedies (advice schema has free-text remedies, not the pack's remedy list); (4) the test case mirrors Naqvi so the corpus contains the near-exact analogue, which is not a hard test.
